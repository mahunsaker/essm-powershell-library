# Asset status states

- **example** — for training/demonstration only; review before operational use.
- **candidate** — reusable code prepared for review; not yet runtime-tested.
- **tested** — tests run for a specified PowerShell version and operating system, evidence recorded.
- **approved** — deployment explicitly authorized for its specified scope and environment.
- **deprecated** — maintained for reference and historical compatibility, not for new development.

Status should not be inferred from filenames, ZIP creation or syntax linting. Versioned implementations with the same function name remain separate until compatibility and behavior are compared.
