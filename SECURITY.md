# Security policy

Please do **not** publish keys, passwords, certificates with private keys, internal network details, production logs, customer data, or proprietary employer source.

Report suspected exposures to the maintainer privately. Remove sensitive material from working trees before a commit. Removing it only from the latest commit does not erase prior history; rewrite repository history and rotate any exposed credentials if an incident occurs.

All sample tools are intended for authorized lab use. Scripts must be reviewed before use on managed endpoints. No script depends on a cloud service to run.
